클로드 코드로 이 블로그를 만들면서 웹페이지가 세 가지 언어로 나뉘어 만들어진다는 것을 배웠습니다. 각각 맡은 일이 달라서, 사람 몸에 빗대면 이해하기 쉬웠습니다.

| 언어 | 역할 | 사람 몸에 빗대면 |
|:---|:---|:---|
| HTML | 페이지의 구조와 내용 | 뼈대 |
| CSS | 색, 글꼴, 배치 같은 겉모습 | 옷과 외모 |
| JavaScript | 클릭했을 때의 반응과 동작 | 근육과 움직임 |

## HTML: 무엇이 있는지 정한다

HTML은 페이지에 어떤 내용이 들어가는지 알려줍니다. 제목, 문단, 버튼, 링크가 모두 HTML로 적힌 요소입니다.

이 블로그에서는 `index.html` 파일 하나가 맡고 있습니다. 머리말(`<header>`), 본문(`<main>`), 꼬리말(`<footer>`)처럼 뜻이 있는 태그를 쓰면 사람도, 검색 엔진도, 화면을 읽어주는 프로그램도 페이지 구조를 쉽게 이해합니다.

## CSS: 어떻게 보일지 정한다

CSS는 같은 HTML을 전혀 다른 모습으로 바꿔 줍니다. 글자 크기, 줄 간격, 여백, 색이 모두 CSS의 일입니다.

이 블로그에서 가장 재미있었던 부분은 다크 모드입니다. 색을 변수로 한곳에 모아 두고, 다크 모드일 때 그 값만 바꾸면 사이트 전체의 색이 한 번에 바뀝니다.

```css
:root {
  --color-bg: #fdfdfc;
  --color-text: #1f2328;
}

:root[data-theme="dark"] {
  --color-bg: #17181a;
  --color-text: #e4e4e1;
}
```

모바일 화면 대응도 CSS가 맡습니다. 작은 화면을 기준으로 먼저 만들고, 화면이 넓어지면 여백과 크기를 키우는 방식입니다.

## JavaScript: 어떻게 움직일지 정한다

JavaScript가 없으면 페이지는 그림처럼 가만히 있습니다. 이 블로그에서 JavaScript가 하는 일은 크게 세 가지입니다.

- 마크다운 파일을 불러와서 웹페이지 형태로 바꿉니다.
- 주소가 바뀌면 글 목록과 글 화면을 갈아 끼웁니다.
- 다크 모드 버튼을 누르면 테마를 바꾸고, 선택한 테마를 브라우저에 저장합니다.

## 세 가지가 함께 일하는 모습

다크 모드 버튼 하나만 봐도 세 언어가 모두 등장합니다.

1. HTML이 버튼을 만듭니다.
2. CSS가 버튼의 모양과 다크 모드일 때의 색을 정합니다.
3. JavaScript가 클릭을 알아채고 테마를 바꿉니다.

> 구조는 HTML, 겉모습은 CSS, 동작은 JavaScript. 역할을 나눠 두니 하나를 고쳐도 다른 것이 망가지지 않습니다.

## 오늘의 결론

처음에는 파일이 여러 개로 나뉘어 있어서 복잡해 보였습니다. 하지만 "이 파일은 무엇을 맡는가"만 기억하면 어디를 고쳐야 할지 금방 알 수 있었습니다. 글 모양을 바꾸고 싶으면 CSS, 버튼 동작을 바꾸고 싶으면 JavaScript, 내용을 바꾸고 싶으면 HTML이나 마크다운 파일을 열면 됩니다.
